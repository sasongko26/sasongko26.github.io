File dengan ekstensi `.pl` adalah file berisi _script_ bahasa pemrograman **perl** atau dengan kata lain adalah _source code_ program yang ditulis dengan **perl**. Kita bisa membuka file ini dengan mudah di **linux**. Mengapa? Karena membuka file pl tidak perlu install program tambahan. Bisa pakai _tool_ standar seperti `cat` atau `less` ataupun `more`. Bisa juga dengan teks editor seperti `vi`, `vim`, `emacs` dan `nano`.

Cara membukanya, masuk terminal jalankan _tool_ yang digunakan diikuti nama filenya. Contoh akan membuka `nama_file.pl` bisa menggunakan salah satu dari

```shell
cat nama_file.pl
less nama_file.pl
more nama_file.pl
vi nama_file.pl
vim nama_file.pl
emacs nama_file.pl
nano nama_file.pl
```
