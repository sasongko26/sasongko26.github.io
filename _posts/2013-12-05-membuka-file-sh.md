File dengan ekstensi `.sh` adalah file berisi _script_ bahasa pemrograman **shell** atau dengan kata lain adalah _source code_ program yang ditulis dengan **shell**. Kita bisa membuka file ini dengan mudah di **linux**. Mengapa? Karena membuka file sh tidak perlu install program tambahan. Bisa pakai _tool_ standar seperti `cat` atau `less` ataupun `more`. Bisa juga dengan teks editor seperti `vi`, `vim`, `emacs` dan `nano`.

Cara membukanya, masuk terminal jalankan _tool_ yang digunakan diikuti nama filenya. Contoh akan membuka `nama_file.sh` bisa menggunakan salah satu dari

```shell
cat nama_file.sh
less nama_file.sh
more nama_file.sh
vi nama_file.sh
vim nama_file.sh
emacs nama_file.sh
nano nama_file.sh
```
