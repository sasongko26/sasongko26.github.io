**Python** memiliki beberapa tipe data, yaitu :

1.  None
2.  Numeric
3.  Boolean
4.  Sequence
5.  Set
6.  Map

# Tipe data python none

Hanya memiliki 1 nilai yaitu None

# Tipe data numeric

Tipe data numeric terdiri atas tipe data **integer** dan **float**. Integer merupakan bilangan bulat. Float merupakan bilangan desimal.

# Tipe data boolean

Terdiri dari 2 nilai yaitu **True** dan **False**

# Tipe data sequence

Ada 3 macam yaitu **string**, **list** dan **tuple**

## Tipe data string

Data ini diapit oleh ' atau ". Contoh :

```python
nama = "sasongko"
alamat = 'indonesia'
```

## Tipe data list

Datanya diapit kurung siku, bersifat *mutable*, antarelement dipisahkan tanda koma. Contoh :

```python
buah = ['pisang', 'mangga', 'melon']
```

## Tipe data tuple

Datanya diapit kurung biasa, *immutable*, antarelement dipisahkan koma. Contoh :

```python
umur_responden = (30, 28, 29, 32, 33, 30, 35, 28, 29)
```

# Tipe data set

Seperti tuple tetapi elemennya unik.
