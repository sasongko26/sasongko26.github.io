File dengan ekstensi `.py` adalah file berisi _script_ bahasa pemrograman **python** atau dengan kata lain adalah _source code_ program yang ditulis dengan **python**. Kita bisa membuka file ini dengan mudah di **linux**. Mengapa? Karena membuka file py tidak perlu install program tambahan. Bisa pakai _tool_ standar seperti `cat` atau `less` ataupun `more`. Bisa juga dengan teks editor seperti `vi`, `vim`, `emacs` dan `nano`.

Cara membukanya, masuk terminal jalankan _tool_ yang digunakan diikuti nama filenya. Contoh akan membuka `nama_file.py` bisa menggunakan salah satu dari

```shell
cat nama_file.py
less nama_file.py
more nama_file.py
vi nama_file.py
vim nama_file.py
emacs nama_file.py
nano nama_file.py
```
