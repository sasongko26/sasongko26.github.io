File dengan ekstensi `.rs` adalah file berisi _script_ bahasa pemrograman **rust** atau dengan kata lain adalah _source code_ program yang ditulis dengan **rust**. Kita bisa membuka file ini dengan mudah di **linux**. Mengapa? Karena membuka file rs tidak perlu install program tambahan. Bisa pakai _tool_ standar seperti `cat` atau `less` ataupun `more`. Bisa juga dengan teks editor seperti `vi`, `vim`, `emacs` dan `nano`.

Cara membukanya, masuk terminal jalankan _tool_ yang digunakan diikuti nama filenya. Contoh akan membuka `nama_file.rs` bisa menggunakan salah satu dari

```rust
cat nama_file.rs
less nama_file.rs
more nama_file.rs
vi nama_file.rs
vim nama_file.rs
emacs nama_file.rs
nano nama_file.rs
```
