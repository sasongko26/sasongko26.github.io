File dengan ekstensi `.md` adalah file berisi _script_ bahasa pemrograman **markdown** atau dengan kata lain adalah _source code_ program yang ditulis dengan **markdown**. Kita bisa membuka file ini dengan mudah di **linux**. Mengapa? Karena membuka file md tidak perlu install program tambahan. Bisa pakai _tool_ standar seperti `cat` atau `less` ataupun `more`. Bisa juga dengan teks editor seperti `vi`, `vim`, `emacs` dan `nano`.

Cara membukanya, masuk terminal jalankan _tool_ yang digunakan diikuti nama filenya. Contoh akan membuka `nama_file.md` bisa menggunakan salah satu dari

```markdown
cat nama_file.md
less nama_file.md
more nama_file.md
vi nama_file.md
vim nama_file.md
emacs nama_file.md
nano nama_file.md
```
